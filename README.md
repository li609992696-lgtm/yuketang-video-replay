# 雨课堂视频补播助手

视频已经播到片尾，观看日志里却还有没看过的区间？这个油猴脚本会读取雨课堂新版学习空间的观看日志，找到缺口，自动补播。

## 主要功能

- 自动识别未观看区间，前后各留 10 秒，相邻区间自动合并。
- 默认静音，优先使用播放器自带的 2 倍速。
- 每段播完后重新读取日志，平台确认本节已完成后再切换视频。

## 使用方法

1. 在浏览器中安装篡改猴（Tampermonkey）。
2. 下载本仓库的 `.user.js` 文件，在篡改猴管理面板中导入。
3. 刷新雨课堂视频页，点击“开始补播”。
